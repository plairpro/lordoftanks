# Квартал

Изометрическая танковая PvP-дуэль в городе. Победа — подбить танк соперника или снести его статую.

- Бой с ботом или с другом по ссылке (P2P через Trystero и публичные MQTT-брокеры, без своего сервера).
- Управление: WASD + мышь; на телефоне и планшете — левый стик ведёт танк, правый крутит башню, отпустил — выстрел.
- Танки: Стриж, Таран, Бастион, Жало — по 12 очков на скорость, броню, скорострельность и пробитие.

Ассеты: Quaternius — Downtown City MegaKit и Animated Tanks Pack (CC0), quaternius.com.
